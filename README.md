Udemy Clone – HTML & CSS

A beginner-friendly Udemy Clone built using HTML and CSS, designed to recreate the look and feel of an online learning platform. The project focuses on practicing HTML structure, CSS styling, layouts, navigation, course cards, and responsive design concepts.

Technologies Used:

HTML5
CSS3

Key Features:

Navigation bar
Course categories
Course cards and sections
Search bar UI
Styled buttons and links
Clean and structured layout
Responsive design concepts

This project was created as a practice project to strengthen my HTML and CSS fundamentals and understand how real-world websites are structured.
